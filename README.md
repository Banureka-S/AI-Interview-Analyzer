# 🤖 AI Interview Analyzer

## 📌 Description
AI Interview Analyzer is a Streamlit-based web application that analyzes resumes, calculates an ATS score, detects technical skills, identifies missing skills, and provides interview questions.

## 🚀 Features

- Resume Upload (PDF)
- Resume Preview
- ATS Score
- Skill Detection
- Missing Skills
- Resume Suggestions
- Strengths & Weaknesses
- Interview Questions
- Download Report

## 🛠 Technologies Used

- Python
- Streamlit
- PyPDF2
- ReportLab
- Pandas

## 📂 Project Structure

```
AI_Interview_Analyzer

```
